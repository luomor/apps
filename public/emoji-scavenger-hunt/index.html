About this game 🤳

Emoji Scavenger Hunt is a browser-based game built with machine learning that uses your phone’s camera and a neural network to try and guess what it’s seeing. This is just one example of how machine learning can be used in fun ways.

Powered by Tensorflow.js, the game is built to run efficiently on your phone’s web browser without needing to access backend servers. No images from your camera are collected or stored.

Watch the video above to see how the project was created, browse the open-source code on GitHub to learn more about how it works, or explore more A.I. Experiments like this.

This experiment was made by friends from the Brand Studio and PAIR teams at Google.

Faq 🙋

- It doesn’t work on my phone.

Being an experiment and all, we're using the latest web technologies. It works best on phones & browsers like the latest version of Chrome on Google Pixel or other smartphones running the latest Android OS, or Safari on newer iPhones running the latest iOS.

- Why doesn’t it recognize some items?

It’s an experiment, and well, not perfect. We think seeing what works and what doesn’t is one way to help explore and understand how machine learning works.

- Are my images being stored on Google servers?

No. All the interactions are happening locally on your device. If you’re curious, check out our open-source code on GitHub
