## 技术栈

- **主页面**: Vue.js + Vite + Element UI
- **子应用**: 原生 JS / Canvas / WebGL / PyScript 等
- **部署**: 静态文件托管
- **统计**: Google Analytics + 百度统计
- **广告**: Google AdSense

## 项目结构

```
public/
├── index.html                 # 主入口页（SPA）
├── assets/
│   ├── index-apps.*.js        # 主应用 JS 包
│   ├── index-apps.*.css       # 主应用 CSS 包
│   └── apps.json              # 应用列表配置
└── <app-name>/                # 各独立子应用
```
